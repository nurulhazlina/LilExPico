Tier 2 Debug — Find & Fix 3 Bugs Each broken line below has one error. Write the corrected line in the input.

Three common mistakes students make when writing their first LED blink program. Fix each broken line — type the corrected MicroPython line exactly.

🐞 Bug 1 — SyntaxError: missing colon

The while statement is missing something. Python will throw a SyntaxError and refuse to run.

while True

Hint: every compound statement in Python ends with a specific punctuation mark.

🐞 Bug 2 — Logic Error: wrong Pin mode

The pin is set to input mode instead of output mode. The LED will never turn on because no voltage can be driven.

led = machine.Pin(25, machine.Pin.IN)

Hint: to control (write to) a pin, what direction mode should it be?

🐞 Bug 3 — TypeError: missing argument

time.sleep() is called without telling Python how long to wait. This causes a TypeError at runtime.

time.sleep()

Hint: for a half-second blink interval, what number goes inside the parentheses?
