Fill in each blank:

1 import ___ , time — the hardware control module
2 machine.Pin.___ — set pin as input (reading)
3 machine.Pin.___ — internal resistor holds pin HIGH when open
4 while ___: — loop condition that runs forever
5 if btn.value() == ___: — with PULL_UP, pressing connects pin to GND
6 led.___()  — method to turn LED on (not toggle)
Tier 2 — Debug Diagnosis & Analysis Bloom’s: Analyze

The three code lines below each contain one bug. Identify and fix each bug — pay attention to pin direction, pull-up logic, and what value() returns when a button is pressed.

Bug 1 — Wrong pin direction

Buggy line:

btn = machine.Pin(14, machine.Pin.OUT, machine.Pin.PULL_UP)
💡 Hint: A button is a physical input device — it sends data TO the Pico, not from it.

Bug 2 — Wrong pressed-state value

Buggy line:

if btn.value() == 1: # trigger when pressed
💡 Hint: A PULL_UP resistor holds the pin HIGH. What level does pressing the button create?

Bug 3 — Missing parentheses on method call

Buggy line:

led.on # turn LED on
💡 Hint: on is a method, not a property — it must be called with ().
